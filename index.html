Privacy Policy

Last updated: November 4, 2026

Welcome to Snake Classic. This Privacy Policy explains how the Snake Classic Chrome extension handles user information.

1. Information Collection

Snake Classic does not collect personally identifiable information or transmit personal data to external servers. The extension does not require users to create an account or provide personal information.

2. Local Storage

Snake Classic uses Chrome's local storage API (chrome.storage.local) to save game-related preferences and progress, including:

  • Highest game score
  • Preferred difficulty level
  • Sound preferences
  • Other game-related settings

This information is stored locally in the user's browser and is not transmitted to external servers.

3. Third-Party Services

Snake Classic does not use third-party analytics, advertising networks, or tracking services. The extension does not share user data with third parties.

4. Data Security and Control

Game preferences and scores are stored using Chrome's local storage functionality. Users can manage or clear this locally stored information through Chrome's extension data controls.

5. Children's Privacy

Snake Classic does not knowingly collect personal information from children or other users.

6. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time to reflect changes in the extension or its privacy practices. Any updates will be published on this page.

7. Contact

If you have questions about this Privacy Policy, please contact the publisher using the contact email listed on the Snake Classic Chrome Web Store page.
