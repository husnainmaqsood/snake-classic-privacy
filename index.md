# Privacy Policy – Snake Classic

**Last updated:** November 4, 2026

## 1. Introduction

Snake Classic is a free arcade game available as a Chrome browser extension. This Privacy Policy explains how the extension handles user information.

## 2. Information Collection

Snake Classic does not collect personally identifiable information, track users, or transmit personal data to external servers.

No account or registration is required to play the game.

## 3. Local Storage

Snake Classic uses Chrome's `chrome.storage.local` API to store game-related information, including:

- Highest game score
- Preferred difficulty level
- Sound preferences
- Other game settings

This information is stored locally in the user's browser and is not transmitted to external servers.

## 4. Third-Party Services

Snake Classic does not use third-party analytics, advertising networks, or tracking services.

The extension does not sell, share, or transfer user data to third parties.

## 5. Data Security and Control

Game scores and preferences remain in the browser's local storage. Users can clear this information through Chrome's extension data controls or by uninstalling the extension.

## 6. Children's Privacy

Snake Classic does not knowingly collect personal information from children or other users.

## 7. Changes to This Policy

This Privacy Policy may be updated if the extension's functionality or data practices change. Any updates will be published on this page.

## 8. Contact

For privacy-related questions, please contact the publisher using the contact email provided on the Snake Classic Chrome Web Store listing.
